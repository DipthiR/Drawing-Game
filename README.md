# Drawing-Game
# Simple Drawing Game with Erase Option

This is a simple drawing game where you can draw freely on a canvas and erase your drawings. You can toggle between drawing and erasing modes using the **E** key.

## Features:
- Draw with the mouse in **black** color.
- Erase your drawings using the **E** key to toggle between drawing and erasing modes. Erasing is done using white lines.
- Clear background (white) that doesn't reset when drawing, allowing you to continue drawing without interruptions.

## Requirements:
- Python 3.x
- `pygame` library

## Installation:
1. Make sure you have Python installed on your computer. You can download it from [python.org](https://www.python.org/downloads/).
2. Install the `pygame` library by running the following command in your terminal or command prompt:

   ```bash
   pip install pygame
   ```
## How to Run:
Save the Python script (from the provided code) to a file, e.g., drawing_game.py.

Open a terminal or command prompt and navigate to the directory where your drawing_game.py file is saved.

Run the Python script:

python drawing_game.py
A window will open where you can draw on the canvas. Press E to toggle between drawing and erasing modes.

Controls:
Mouse: Click and drag to draw.

E key: Toggle between drawing and erasing modes.

When in draw mode, you can draw with a black line.

When in erase mode, you can erase your drawings with a white line.
